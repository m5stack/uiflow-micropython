# OP180 Unit

The following products are supported:

    OP180

Micropython Example:
```python
import os, sys, io
import M5
from M5 import *
import time
from unit import OPUnit

op180_0 = None

def setup():
    global op180_0

    op180_0 = OPUnit((8, 9), type=1)
    M5.begin()
    Widgets.fillScreen(0x222222)

    print(op180_0.get_value)
    time.sleep(1)
    print(op180_0.count_value)
    time.sleep(1)
    op180_0.count_reset()
    time.sleep(1)
```

## class OPUnit

## Constructors

Import with `from unit import OPUnit`.

### `class OPUnit(port, active_low=True, type=1)`

    Create an OPUnit object.

    The parameters is:
        - `port` is a pin tuple; port[0] is the detection pin.
        - `active_low` defaults to True.
        - `type` is 1 (switch, default) or 2 (edge counter).

## Methods

### `OPUnit.count_value`

    Current integer edge count. Read `op180_0.count_value` without parentheses.
    Edge counting is enabled by constructing the Unit with `type=2`.

### `OPUnit.count_reset()`

    Reset the meter value.
