# Stamp LoRa-1262

Stamp LoRa-1262 is an SX1262 LoRa transceiver for the Stamp Series FPC12
interface. `StampLoRa1262` selects the current host's FPC12 GPIO mapping,
enables the RF switch, and provides synchronous send, receive, and radio
configuration operations.

Support the following products:

    Stamp LoRa-1262

The following are the host's support for Stamp LoRa-1262:

    - - Controller
      - Status
    - - StampC5
      - S
    - - StampC6
      - S
    - - StampS3Mini
      - S

The supported RF frequency range is 868-923 MHz. Attach a suitable antenna
before transmitting. The module's `SHUT_DOWN` signal is not part of the
Stamp Series FPC12 interface and is not controlled by this driver.

## MicroPython Example

#### Sender

```python
import time

import M5
from stamp import StampLoRa1262

radio = None
sequence = None

def setup():
    global radio, sequence

    M5.begin()
    radio = StampLoRa1262()
    sequence = 0

def loop():
    global radio, sequence

    M5.update()
    message = "Stamp LoRa1262 %d" % sequence
    radio.send(message)
    print("sent:", message)
    sequence = (sequence + 1) & 0xFF
    time.sleep_ms(1000)

if __name__ == "__main__":
    try:
        setup()
        while True:
            loop()
    except (Exception, KeyboardInterrupt) as e:
        try:
            from utility import print_error_msg

            print_error_msg(e)
        except ImportError:
            print("please update to latest firmware")
```

#### Receiver

```python
import M5
from stamp import StampLoRa1262

radio = None

def receive_event(packet):
    print("received:", packet.decode())
    print("rssi:", packet.rssi, "snr:", packet.snr / 4)

def setup():
    global radio

    M5.begin()
    radio = StampLoRa1262()
    radio.set_rx_callback(receive_event)
    radio.start_recv()

def loop():
    M5.update()

if __name__ == "__main__":
    try:
        setup()
        while True:
            loop()
    except (Exception, KeyboardInterrupt) as e:
        try:
            from utility import print_error_msg

            print_error_msg(e)
        except ImportError:
            print("please update to latest firmware")
```

## API

## `StampLoRa1262`
SX1262 LoRa radio connected through the Stamp FPC12 interface.

Passing `None` for a pin uses the current Stamp host's FPC12 mapping.
StampC5, StampC6, and StampS3Mini are supported by default. Other hosts
can be used when every signal pin is provided explicitly.

### `set_freq`
Set the LoRa carrier frequency.

- Parameter `freq_khz` (`int`): Carrier frequency in kHz, from 868000 to 923000.

```python
radio.set_freq(868000)
```

### `set_sf`
Set the LoRa spreading factor.

- Parameter `sf` (`int`): Spreading factor, from 6 to 12.

```python
radio.set_sf(8)
```

### `set_bw`
Set the LoRa bandwidth.

- Parameter `bw` (`str`): Bandwidth in kHz. Use one of `BANDWIDTHS`.

```python
radio.set_bw("250")
```

### `set_coding_rate`
Set the coding-rate denominator for 4/N coding.

- Parameter `coding_rate` (`int`): Coding-rate denominator, from 5 to 8.

```python
radio.set_coding_rate(8)
```

### `set_syncword`
Set the LoRa sync word.

- Parameter `syncword` (`int`): Sync word value, from 1 to 255.

```python
radio.set_syncword(0x12)
```

### `set_preamble_len`
Set the LoRa preamble length.

- Parameter `preamble_len` (`int`): Preamble length in symbols, from 5 to 255.

```python
radio.set_preamble_len(12)
```

### `set_output_power`
Set the LoRa output power.

- Parameter `output_power` (`int`): Output power in dBm, from -9 to 22.

```python
radio.set_output_power(10)
```

### `send`
Send a packet and return its transmission timestamp.

- Parameter `packet`: String, bytes-like object, list, tuple, or integer
               payload. Strings are encoded as UTF-8 and integers are
               sent as one-byte payloads.
- Parameter `tx_at_ms` (`int`): Optional scheduled transmission timestamp.
- Returns: Transmission timestamp in milliseconds.
- Return type: int

```python
radio.send("hello")
```

### `recv`
Receive one packet.

- Parameter `timeout_ms` (`int`): Optional receive timeout in milliseconds.
- Parameter `rx_length` (`int`): Maximum receive length in bytes.
- Parameter `rx_packet` (`RxPacket`): Optional packet object to reuse.
- Returns: Received packet, or `None` on timeout.
- Return type: RxPacket or None

```python
packet = radio.recv(timeout_ms=1000)
```

### `start_recv`
Start continuous packet reception.

```python
radio.start_recv()
```

### `set_tx_callback`
Register a callback for completed transmissions.

- Parameter `callback`: A no-argument callable, or `None` to clear it.

```python
radio.set_tx_callback(on_transmit)
```

### `set_rx_callback`
Register a callback for valid packets in continuous reception.

- Parameter `A callable accepting one` (`callback:`): class:`lora.RxPacket`, or
                 `None` to clear it. Call `start_recv` to
                 enable continuous reception.

```python
radio.set_rx_callback(on_receive)
```

### `standby`
Put the radio in standby mode and stop continuous reception.

```python
radio.standby()
```

### `sleep`
Put the radio in sleep mode and stop continuous reception.

```python
radio.sleep()
```

### `irq_triggered`
Return whether a radio IRQ has been triggered.

- Returns: `True` if an IRQ is pending; otherwise `False`.
- Return type: bool

```python
radio.irq_triggered()
```

### `deinit`
Stop reception and put the radio in sleep mode.

    Use the deinit block in UiFlow2.

```python
radio.deinit()
```
