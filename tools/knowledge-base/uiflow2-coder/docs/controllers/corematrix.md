# CoreMatrix

Support the following products:

    CoreMatrix

## Supported Components

The CoreMatrix firmware includes the following user-facing packages:

- `Module`: The `module` package for M-BUS expansion modules.
- `Unit`: The `unit` package containing Unit drivers.
- `Chain`: The `chain` package for Chain devices.

## Board Features

CoreMatrix supports the following built-in functions and peripherals:

- 16 x 16 LED matrix output through `M5.Display`.
- Three button inputs through `M5.BtnA`, `M5.BtnB`, and `M5.BtnC`.
- BMI270 accelerometer and gyroscope readings through `M5.Imu`.
- Buzzer tone output through `M5.Speaker`.
- Battery, VBUS, charging, and external output power management through `M5.Power`.
