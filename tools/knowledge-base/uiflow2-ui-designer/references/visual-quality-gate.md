# Visual Quality Gate

可见 UI 只有通过产品级视觉检查才算完成。代码能导入、API 正确或串口无异常，不代表
页面已经美观、可读或无闪烁。

## 证据等级

- **静态检查**：只能证明代码、API、布局计算和资源策略合理；视觉结论为
  `NOT RUN`。
- **模拟器/渲染截图**：可检查布局、文字、颜色、背景和静态状态；真实屏幕色彩、
  触摸、闪烁、撕裂、帧率与功耗仍是 `PARTIAL`。
- **新鲜设备相机画面或人工实机观察**：可检查真实显示外观；持续动画还需要观察
  运动过程，单帧不能证明无闪烁或转场正确。

有可用渲染画面时，执行“渲染 → 检查 → 定向修正 → 重新渲染”，直到通过或达到
设备/资源约束下的最佳结果。没有渲染工具时不要伪造截图，也不要声称视觉 PASS。

## 最低验收

### 视觉层级

- 页面有一个清晰主焦点，主/次/辅助信息可在几秒内区分。
- 主操作强于次操作；错误、警告和正常状态不靠颜色单独表达。
- 主控件大小匹配屏幕，不是一个小控件孤零零放在大面积空白中。

### 构图与完成度

- 页面有明确的上/中/下、左右分区、径向层级或其他有意图的结构。
- 空白用于分组和聚焦，不是因为内容未完成；相关元素在视觉和代码结构上成组。
- 页面看起来像可交付产品界面，而不是默认控件散放在 Canvas 上。
- supporting status、单位、更新时间和必要操作完整，但不抢夺主焦点。

### 设计系统一致性

- 颜色、字体、间距、圆角、边框、表面和状态反馈来自同一套 token。
- 重复元素尺寸、对齐和间距一致。
- 页面背景、控件背景和可见 part/state 协调，没有无意图的默认白块、默认蓝色、
  浅灰边框或不透明底板。
- `M5Arc`、`M5Scale`、`M5Spinner` 等叠加型控件没有意外矩形背板；只有文档和
  源码确认支持时才设置对应透明度/part。

### 文字与可用性

- 所有标题、按钮、状态、单位、列表行、表格单元和错误信息在目标字体下完整可见。
- 动态值使用最长合理样例检查；多语言页面逐种语言检查宽度、换行和 glyph 覆盖。
- 没有 tofu、乱码、错误字体命名空间或在拉丁字体中遗留 CJK 原生脚本。
- 触摸控件大小和间隔可操作，文字控件不因内容变化而改变布局尺寸。

### 边界与滚动

- 子元素位于父区域和屏幕安全区内；圆屏四角没有关键内容。
- 没有裁切的文字、图标、圆角、阴影、图表、刻度或 Canvas 边缘。
- page、card、header、footer、dashboard 和普通分组默认不滚动；只为长列表、表格、
  表单或日志保留有意图的滚动。
- 意外出现滚动条时先修复边界或布局；只有当前文档/源码确认相关 flag/part 后才修改
  滚动属性，禁止猜测。

### 交互审计

- 每个看起来可点击、可切换或可编辑的控件都有已验证回调，或者明确呈现 disabled。
- pressed/focused/selected/disabled 状态与 normal 可区分，反馈不引发布局跳动。
- 回调只更新轻量状态或请求标志；长任务不会阻塞 `M5.update()`。
- 操作结果有 success/error/offline 反馈，失败状态包含下一步。

### 动效审计

- 每个动画有触发条件、目标、开始状态、持续时间、结束条件和重复策略。
- 不存在永不结束的装饰动画、空状态转场、多个路径同时写同一属性或不可达动画。
- 静态截图只检查初始/结束构图；必须通过模拟器预览或设备观察才能评价节奏、闪烁、
  撕裂和掉帧。
- EPD 不使用连续动画，LED Matrix 使用有限关键帧；LCD 动效遵守帧率和内存预算。

### 图片与资源

- 图片像素尺寸接近目标控件，保持比例；图标优先透明背景，不用大图缩成小图浪费 RAM。
- 文件格式、路径、缩放和解码方式来自当前 UIFlow2 文档，不编造资源 URI。
- 图片只作辅助时必须有文字、形状或状态色提供等价含义。

## 拒绝条件

出现以下任一情况，不得将设计标为完成：

- 仍像未经设计的默认 LVGL/m5ui 控件集合。
- 没有主视觉中心，所有卡片或按钮权重相同。
- 默认白底、默认蓝色或不匹配的多 part 背景破坏主题。
- 有裁切、重叠、意外滚动条、明显空洞或漂浮控件。
- 文字需要小于可读字号才能勉强放入，或多语言出现缺字。
- 控件看起来可操作但没有回调，动画存在但没有触发或结束条件。
- 只有静态检查却声称真实设备视觉、触摸、动画或无闪烁 PASS。

若由于 API、内存、屏幕尺寸或缺少渲染工具无法完全修复，保留最佳可行方案并明确：
已验证项、未验证项、剩余视觉问题和需要的设备/模拟器确认步骤。
