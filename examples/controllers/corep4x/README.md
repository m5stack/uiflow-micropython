# CoreP4X UiFlow2 示例

页面标题不带产品型号前缀。IMU 的 Accel、Gyro 上下分组，各自逐行显示 X/Y/Z，标签底色与页面一致。Power 标签底色与页面一致，字段名和读数分列对齐；底部两个按钮统一为 204×64，状态切换后保持位置和文字居中。RTC 日期通过原生对齐积木保持水平居中，已移除 Clock/Saved 提示。Speaker 已移除 ES8311 字样。

8 个 `.m5f2` 中，7 个使用 UIFlow2 原生积木；Ethernet 为原生界面组件与 Python 代码块的混合案例。全部不包含打印积木，界面组件可在设计器中编辑。

- `display_touch`：显示测试色与触摸计数。
- `imu`：加速度与陀螺仪读数。
- `power`：显示 USB、电池电压及充电状态，不显示电量百分比；实际检测到充电时电池电压显示绿色，未充电时恢复普通文字颜色。支持 Port A 5 V 与充电许可控制。
- `rtc`：蓝色时钟、设置时分秒。图形化简化版明确使用 **UTC**，读取和写入保持一致；Python 版保留本地时间与 UTC 转换。
- `speaker_tone`：PA 默认开启，音调默认停止；频率、音量各有独立滑条。频率 200～4000 Hz，默认 1000 Hz；音量 0～100%，默认 70%，调用底层接口时换算为 0～255，关闭再打开 PA 保留当前音量。按钮和状态使用 `Start tone`、`Stop tone`、`Playing` 等正常大小写。
- `audio`：参考 StickS3 的 8 kHz 参数，录音与播放统一为 **8 kHz、单声道、16 bit**。当前 CoreP4X 固件没有 StickS3 案例使用的 `audio.Recorder` / `audio.Player`，因此保留 `Mic` / `Speaker` 原生接口。点击 **RECORD** 开始，再次点击 **STOP REC** 停止，最长 30 秒。图形化使用两个 4000 字节缓冲提前排队，每秒 16000 字节，30 秒共 480000 字节；停止时收完队列中的数据，最多约 0.5 秒。支持回放、停止播放和音量调节，PA 默认开启。
- `ir`：使用原生 IR Unit 积木，自定义引脚 RX=G13、TX=G49，对应板载红外；发送 NEC 地址 8，数据递增，显示接收计数，地址与数据以十进制显示。

- `ethernet`：混合案例，界面与同步按钮为原生图形化组件。Python 代码块保留本机已验证的 MDIO=G36、power=G52、显式 RMII 引脚以及 NTP 重试、UTC+8 显示、断网提示和重连同步。原生 `ethernet_init` 的固定引脚不适用于 CoreP4X，因此没有使用该初始化积木。

Audio 音量滑条范围为 **0～100%**，默认 70%；调用 `Speaker.setVolume()` 时换算为 0～255，0% 静音、100% 为最大值。

Board 综合示例已移除。Python 示例没有显式打印；异常清理后由运行环境报告异常。

Audio 8 kHz 图形化生成程序已在 CoreP4X 实机检查：30 秒 / 480000 字节录音实耗 30.024 秒，7.5 秒录音回放耗时 7.53 秒，录音队列未检测到断流；停止播放、播放中切回录音、立即停止通过。使用服务器实际积木注册定义进行 Blockly XML 导入检查，全部字段值保持一致，录音与播放均为 8000；按钮尺寸通过原生积木显式设置，不再使用服务器不支持的 DISABLED 状态枚举。该检查为无界面导入，尚未代替用户在 IDE 中下载后的人声听音确认。

验证：8 个图形化项目通过积木目录校验，目录生成器输出经过语法检查；LVGL 9.3 / m5ui、480×480 模拟器检查主要触摸交互。Ethernet 检查正确引脚、同步、断网与 NTP 超时。模拟器硬件读数为测试替身。完整新版固件在 CoreP4X 实机验证了 IR 在 GC 后连续发送/接收 40 次、Speaker 默认 PA 开启而音调停止、RTC 蓝色界面；这些实机检查运行的是配套 Python 示例，不能代替全部图形化案例的 IDE 下载验证。
