Button Counter
^^^^^^^^^^^^^^

Open the |paperdiy_button_counter_example.m5f2| project in UiFlow2.

Charge Detection
^^^^^^^^^^^^^^^^

Open the |paperdiy_charge_detection_example.m5f2| project in UiFlow2.

This example displays battery voltage, USB voltage, and charging status. Press Button A to enable or disable battery charging.
