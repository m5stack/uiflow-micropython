LoRa-1262 Module
====================

.. py:currentmodule:: module.lora1262

.. include:: ../refs/module.lora1262.ref

``LoRa1262Module`` provides LoRa communication through the Module13.2
LoRa-1262 radio. The radio uses the module M-Bus SPI bus and an M5IOE1
controller on I2C for reset, antenna-switch, and power control.

Support the following product:

    |LoRa-1262 Module|

The constructor accepts an initialized ``machine.I2C`` bus. When ``i2c`` is
omitted, the module uses ``module.mbus.i2c1``. The M5IOE1 address must be in
the range ``0x71`` through ``0x74``.

.. note::

   Attach a suitable antenna before transmitting. The supported RF frequency
   range is 850000--930000 kHz.

receive timestamp.
